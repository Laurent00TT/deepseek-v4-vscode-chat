# AI Study

A project folder for studying and experimenting with AI / machine learning topics.

## Structure

```
ai-study/
├── README.md          # This file
├── notes/             # Study notes and summaries
├── notebooks/         # Jupyter notebooks and experiments
├── datasets/          # Datasets used for experiments (gitignored)
└── projects/          # Hands-on mini-projects
```

## Goals

- [ ] Understand core machine learning concepts
- [ ] Practice with neural networks and deep learning
- [ ] Explore large language models (LLMs)
- [ ] Build small end-to-end projects

## Getting Started

Add your study materials to the relevant subfolders. Keep notes in
`notes/`, experiments in `notebooks/`, and finished work in `projects/`.
